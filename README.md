# 🧞 Genie-AI Photo Editor

Genie is a **AI Photo Editor** web application built using **React**, **Next.** js, and **Tailwind CSS**, as well as manually integrated with **Google Gemini API**.

With Genie, users can edit photos using artificial intelligence. To maintain security and flexibility, users are required to **manually enter their own API Key** before being able to use the photo editing feature.

---

## 🚀 Main Features

- ✨ Edit AI-based photos with Google Gemini

- 🔐 Manual API key input (without backend)

- ⚡ Fast and responsive (built with Next.js & Tailwind CSS)

- 🎨 Modern and minimalistic UI

---

# The technology used

- **React.js * * - main frontend Library

- **Next.JS * * - React Framework for SSR & optimization

- **Tailwind CSS * * -Utility-first CSS framework

- **Google Gemini API* – - for AI-based photo processing and editing

---

## 📦 Installing and running on Localhost

Follow these steps to clone and run Genie on your local computer:

npm install

npm run dev

## ✨ Enter Google Gemini API Key

When you first enter the main page, you will be asked to enter the Google Gemini API Key.

You can get the API Key from https://aistudio.google.com/app/apikey

Paste the API Key into the field provided.

After that, the AI photo editing feature will be active.

🔒 Note: your API Key is not saved to any server. All processes run on the client side for maximum security.
